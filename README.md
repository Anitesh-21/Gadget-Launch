# Gadget Launch - Apple Watch Series 10

Welcome to the **Gadget Launch** showcase webpage! This simple HTML project presents the launch of the **Apple Watch Series 10**, featuring key specifications, pricing, comparisons, and more—all in a clean and organized format using basic HTML elements.

## 🌐 Demo

You can view the live webpage by opening the `index.html` file in your browser.

## 📄 Description

This webpage introduces the latest **Apple Watch Series 10** with detailed content including:

- Overview of the watch
- Highlighted features
- Product specifications
- Price (with discount)
- A comparison table between Series 9 and Series 10
- External link to the official Apple website
- Image of the product
- Semantic and accessible HTML elements

## 🚀 Features Used

The webpage demonstrates basic usage of the following HTML tags:

- `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- Headings (`<h1>` to `<h3>`)
- Paragraphs (`<p>`)
- Emphasis (`<strong>`, `<i>`, `<u>`)
- Links (`<a href>`)
- Images (`<img>`)
- Lists (`<ul>`, `<ol>`)
- Tables (`<table>`, `<tr>`, `<td>`, `<th>`)
- Formatting tags like `<del>`, `<br>`, `<hr>`
